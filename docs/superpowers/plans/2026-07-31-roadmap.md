# EvidSight ROADMAP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建 `docs/ROADMAP.md`，以无具体日期的阶段里程碑和验收门禁描述 EvidSight v1.0 实施顺序及 v1.x/P2 演进边界。

**Architecture:** ROADMAP 是产品级实施顺序的权威文档，只聚合 PRD、总体架构、迁移计划和专项规范之间的依赖，不复制字段、算法、状态机或任务级步骤。正文采用固定的 M0—M6 结构，每个里程碑统一说明进入条件、范围、规范、交付物、退出门禁和非目标。

**Tech Stack:** Markdown、Git、ripgrep、POSIX shell

## Global Constraints

- 不写具体日期、周数、工期或未经验证的完成比例。
- 主线固定为 `M0 → M1 → M2 → M3 → M4 → M5 → M6`。
- 状态词只使用 `未开始`、`进行中`、`受阻`、`已完成`。
- 专项事实只链接引用，不在 ROADMAP 重复定义。
- v1.0 P0、v1.x P1 和远期 P2 必须明确分离。
- 不复制迁移计划中的命令、文件级步骤或复选框。
- 当前工作区中的其他修改属于用户；仅修改和提交本计划列出的文件。

- [ ] **Step 5: 验证本地 Markdown 链接**

```bash
python3 - <<'PY'
import pathlib, re
doc = pathlib.Path('docs/ROADMAP.md')
missing = []
for target in re.findall(r'\[[^]]+\]\(([^)#]+)(?:#[^)]+)?\)', doc.read_text()):
    if '://' not in target and not (doc.parent / target).resolve().exists():
        missing.append(target)
if missing:
    raise SystemExit('Missing local links: ' + ', '.join(sorted(set(missing))))
print('All local Markdown links resolve.')
PY
```

Expected: 输出 `All local Markdown links resolve.`。尚未创建的专项文档使用代码路径，不创建死链。
